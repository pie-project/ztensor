A container for tensor data

Every tensor starts on a page of its own.

That one property is what lets a weight be mapped, registered and evicted without dragging its neighbours along. zTensor adds a digest to each one, refuses to execute code, and reads every other format into the same object model.

Read the docs $ cargo add ztensor $ pip install ztensor

The API

It tells you what it can do

Different files support different things. Rather than degrade quietly, every part reports which of these will work — and each field is computed by the very precondition the method checks, so the report cannot drift from the behaviour.

Ask forYou getWhere it works
bytes() The best the file can do, saying whether it borrowed or copied every format
map() A borrow, or an error — never a hidden copy mapped raw parts
locate() The exact byte range, so you can do the I/O yourself raw parts
verify() A digest check over the decoded bytes .zt
evict() Drops these pages, and cannot touch a neighbour's page-exclusive parts
locate() is the rung a GPU loader actually wants: it hands over the address for io_uring, cuFile or a staged host-to-device copy, and keeps the library out of the transfer.

Read anything · write one thing

One loader, one output format

Rust
// Read anything: .zt, .safetensors, .gguf,
// .npz, .pt, .h5, .onnx — detected by magic.
let src = ztensor_compat::open("model.safetensors")?;

for t in src.tensors() {
    println!("{} {:?} {}",
             t.name(), t.shape(), t.dtype()?);
}

let t = src.tensor("layer.0.mlp.w")?;
let bytes = t.map()?;      // zero-copy
let at = t.locate()?;      // or just the address

// Write one thing: canonical .zt.
let mut w = Writer::publish("model.zt")?;
w.ingest(&src)?;
w.finish()?;
Python
with ztensor.open("model.safetensors") as src:
    for t in src:
        print(t.name, t.shape, t.dtype)

    t = src["layer.0.mlp.w"]
    arr = torch.from_dlpack(t)   # zero-copy
    t.location                   # for your own I/O
    t["scales"]                 # parts are tensors too

# DLPack carries bfloat16, which the numpy
# dtype table cannot — so there is no
# per-framework module here at all.
ztensor.convert("model.safetensors", "model.zt")
ztensor.verify("model.zt", deep=True)
Command line
zt ls model.gguf                    # inspect anything
zt convert model.gguf model.zt      # canonical, verifiable output
zt verify model.zt --deep           # structure + digests + shards
zt diff a.safetensors b.zt          # compare across formats

The format

Three layers, so the mortal parts can die alone

A reader needs L0 and L1 to be useful at all. It may refuse anything in L2 it does not recognize — and it must, because silently reinterpreting unknown vocabulary is how a format produces wrong tensors instead of errors.

L0

Container

Frozen

Magic, a 40-byte footer, an aligned blob heap, byte order. It never changes.

L1

Manifest

Version-gated

A deterministic-CBOR schema: objects, parts, blob references, shards. Evolves rarely, behind the footer's version integer.

L2

Vocabulary

Deliberately mortal

Layout profiles, logical types, encodings, digest algorithms — namespaced, versioned, registry-managed, and extensible from outside the crate.
